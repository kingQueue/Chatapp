The code changes when the app restarts. Anyone with the code on your local network can use your room.

If your phone cannot connect, run Allow Phone Access.cmd from the app folder and approve Windows’ administrator prompt. It allows port 8766 only for the app runtime from your local subnet. Keep this feature off on public Wi-Fi.

Your conversations stay with you

Characters, messages, and pinned memories live in data/character-room.sqlite3 inside the app folder. Clearing browser data won’t erase them. Anyone with access to that file can read it.

To restore or move your library, stop the app and copy the entire data folder. JSON export is a readable archive.
